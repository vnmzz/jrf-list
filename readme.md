# JRF List

Target list for JRF, built from the faction forum thread. Shows each target's live Torn status (using your own API key, which stays in your browser) with a one-click Attack button.

**To add or remove targets, edit `data.js`.** Instructions are at the top of that file.

Based on [TC-Baldr's Levelling List](https://github.com/oranweb/tc-baldrs-levelling-list) by Oran [1778676].
